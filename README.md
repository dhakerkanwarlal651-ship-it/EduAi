# EduAI

Mobile-first educational AI study assistant starter.

## Features in this first version
- Responsive mobile UI
- Hindi/English toggle button
- Study search with demo answers
- Courses: Nursery → Class 12, BA/BSc/BCom, MA, UPSC
- Photo question input
- Voice button placeholder
- Study Plan, Revision, Practice Quiz actions
- Bottom navigation
- Ready for GitHub Pages

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `app.js`.
3. Open **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public website link.
